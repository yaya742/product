# 校园地图工具

地图是独立于模型推理的二维交互功能。用户可以直接从标题栏的校园地图入口，或地图结果卡，打开地图；浏览、悬停、搜索、点选、旋转和路线计算不等待模型。

- `map_overview` 返回当前数据版本、范围、覆盖量和缺口。当前范围为紫金港校区与望月公寓（桂花苑）周边。地理数据来自 OpenStreetMap，采用 ODbL 许可；不是浙大官方测绘或实时路况。
- `map_search` 查找名称和已经核实的别名。使用实际返回的稳定地点 ID，不编造 ID、轮廓、入口或建筑关系。同名或多个候选时明确列出区别，让用户选择。
- `map_route` 只接受实际地点 ID，默认步行，目标为已知路网中的长度最小。它比较已连接的可用入口，不用建筑中心到中心的直线，也不把未知入口吸附到最近道路。`ready` 才是有效路线；距离为入口到入口的路网长度。
- 路线结果必须原样保留来源、数据日期、起终点、入口语义和通行限制。门禁、施工和未标注的现实道路不能由本地快照保证。不把“已知图内最短”说成现实世界所有路段上的无条件最短。
- `unknown_entrance` 表示入口资料不足，`unreachable` 表示已有图中没有连接，`outside` 表示当前数据未覆盖，`same` 表示同一地点，`error` 表示数据或服务出错。失败时可以继续浏览，不生成替代的假路线。
- `map_location_status` 只返回定位能力说明；它不主动读取坐标。Windows 本机位置通过地图界面的原生桥接取得，带来源、时间与精度，在地图关闭后停止，不保存轨迹，也不发送给模型。手机位置尚未连接。
- 当前点到路网的步行连接不明确时，要求用户在地图中选择实际起点建筑，不能凭精度范围或最近距离推断已经在某个入口。没有有效位置也能用“两点路线”。
- 历史结果卡需要在当前地图中重新核对地点和路由。不引用停用的数据版本或历史地图图形，不把旧图像当作实时数据。

解释面向用户的地点、来源和可执行操作；不要向用户展示内部文件路径、IPC 名称、原始网络日志或定位坐标。
