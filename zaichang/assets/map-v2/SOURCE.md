# V2 地理数据来源

## 官网检查

2026-09-10 实际访问 [浙江大学电子地图](https://map.zju.edu.cn/index)，并检查页面正常引用的配置与公开接口：

- `resource/imap/js/map.setting.v2.js` 与 `map.loader.v2.js`：当前 2.5D 底图是 WMS 栅格；对象查询层为 `IMAP:hotmap_221027`。
- `resource/imap/js/map.transform.js`：该热点坐标使用旋转 30°、纵向压缩 45°的变换；配置中的 EPSG:32651 标签不能直接当作标准 UTM 数值解释。可点击热点并不证明是地面占地。
- `resource/imap/skin1.0/js/mapswitch.js`：二维入口接入天地图 `vec_c/cva_c` 栅格；页面上未找到可直接重设样式的完整平面校园建筑层。
- `resource/imap/skin1.0/js/icssp.xydh.js`：识别到独立路线服务入口及虚构连接标志，但没有把服务存在当作入口、拓扑或最短性已经验证。
- WFS capabilities 的默认 `AccessConstraints: NONE` 不能代替完整的离线再分发许可。本版本不打包上述官网图像、热点轮廓、公开服务令牌或脚本，也没有把它们描成另一张地图。

## 实际使用的数据

独立获取 [OpenStreetMap](https://www.openstreetmap.org/copyright) 数据，使用公开 Overpass 接口，查询框为 `120.060,30.293,120.101,30.326`。这份数据有明确的 ODbL 1.0 许可，可保留署名后使用、修改与再分发。源库时间、真实取得时间、归一化版本和覆盖统计均记录在 `manifest.json`。

`source.osm.json.gz` 保留源几何、节点/道路关系、标签、对象 ID、版本和更新时间；移除不影响地图重建的编辑者用户名、用户 ID 和变更集字段。生成数据继续按 ODbL 1.0 提供。许可全文位于项目 `licenses/ODbL-1.0.txt`，界面持续显示 © OpenStreetMap contributors。

望月公寓使用 OSM 对象 `way/322644186`。用户于本轮明确补充“望月公寓（桂花苑）”，因此将“桂花苑”作为该片区的可追溯别名；没有据此推断楼号、私人住址或未标注入口。

OSM 输入与存储采用 WGS84 `[经度, 纬度]`。显示仅做 EPSG:4326 → EPSG:3857 投影，不套用 GCJ-02 或百度偏移。真实定位独立携带来源、时间和精度；与地理数据使用同一投影，未把官网截图中的位置当作本机位置。

`import-map-v2.mjs` 保留孔洞和多部件，以源节点建立拓扑，不将几何交叉自动连接，不插入穿墙起步线。完整性、来源和接入能力分开报告：建筑可选中不代表入口已知，入口已知不代表与道路连接，图上最短不代表现场实时可通行。

`core-reference.json` 是本轮覆盖复核的核心清单：西操场/西田径场、东操场/东田径场、风雨操场、中心湖、启真湖、望月公寓、主要校门和求是大道。OSM 对象使用其真实几何；校门和求是大道没有被接入步行图。`official-coverage-reference.json` 只保存当前公开 WFS 的名称、对象 ID、转换后的名称位置和经过同名/空间阈值核验的别名映射，不保存官方 2.5D 面；无法可靠绑定的名称留在审计报告的未绑定集合中。
