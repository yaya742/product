# 浙江大学校园公开信息插件

这是一个符合在场第三方插件规范的只读插件，提供三项能力：

- `school.calendar.read`：读取官方校历页面、官方 PDF 链接，以及 HTML 教学安排中明确出现的日期。
- `school.notices.search`：搜索浙江大学本科教学管理信息服务平台的公开通知，可选读取少量官方详情。
- `school.college.directory`：从浙江大学官方学院目录中定位学院官网入口。

插件只通过宿主提供的 `context.request` 访问以下官方域名：

- `ugrs.zju.edu.cn`
- `zdbk.zju.edu.cn`
- `www.zju.edu.cn`

它不读取或保存统一身份认证账号、密码、Cookie、成绩、课表、校园卡和其他个人校园资料。学院目录中的站点只返回官方入口链接；由于插件出站白名单按精确主机名控制，不会继续抓取未声明的学院子域名。

## 打包

在本目录执行：

```text
npm test
npm run package
```

生成的 `dist/campus-zju-public-plugin.zip` 可以在“在场”的接口设置中导入。插件首次安装后默认停用，需要在宿主界面审核并启用。

## 当前边界

单元测试使用固定响应验证协议、解析和失败边界，不代表远程校园网站当前可用。真实运行仍取决于官方站点的网络、页面结构和访问策略；图片型校历不会被插件自行 OCR。
