# 浙大校园资料本机兼容连接器

这是“在场”PC 端使用的独立只读连接器。它通过浙江大学统一身份认证，在用户主动连接后读取本人课表、课程、考试、成绩、成绩风险提示、绩点汇总，以及素质拓展平台的第二/三/四课堂记点和项目明细；体育课成绩仍以教务网成绩记录为准。校历、节假日教学安排和本科教学通知使用浙大公开页面，不需要账号。

- 连接方式：本机兼容连接，不代表浙江大学官方授权或背书。
- 凭据：仅由 Windows 当前用户的 DPAPI 加密保存，不写入仓库，不进入模型上下文。
- 会话：统一认证和业务站 Cookie 只存在于单次进程内存中。
- 数据：只保存规范化后的最小缓存，不保存原始 HTML、Cookie、票据或完整响应。
- 写操作：不提供选课、报名、签到、审核、提交作业、支付或修改资料能力。
- 状态：`status` 只返回是否已配置和缓存类别，不返回用户名、密码、Cookie 或缓存查询关键词。

命令协议见 `connector.json`。每次命令在 stdout 只输出一个 JSON 对象，诊断信息只写 stderr。
