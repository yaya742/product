# 浙江大学校园信息插件

这是一个符合在场第三方插件规范的只读插件。它保留原有的公开校园信息能力，并把当前项目已有的本机浙大连接器一起打包，支持：

- `school.calendar.read`：读取官方校历页面、官方 PDF 链接，以及 HTML 教学安排中明确出现的日期。
- `school.notices.search`：搜索浙江大学本科教学管理信息服务平台的公开通知，可选读取少量官方详情。
- `school.college.directory`：从浙江大学官方学院目录中定位学院官网入口。
- `school.account.status`：查看本机连接器是否已保存账号、缓存有哪些范围，不返回账号标识或凭据。
- `school.read`：读取课表、课程、考试、待办、学在浙大课程与活动、成绩、成绩风险提示、绩点、素质拓展、体育/实践项目、校历、通知和来源状态。
- `school.overview`：有界整理当前学期学业资料、学在浙大课程和公开校园资料总览。

个人资料使用插件内的 `connector/` 本机兼容连接器。账号和密码仍由 Windows 当前用户 DPAPI 加密保存在本机，插件不会把密码、Cookie、完整学号、校园卡号或身份字段返回给模型。没有配置账号时，`school.overview` 仍会返回公开校历、通知和账号状态，并明确标出个人资料缺口。

插件会访问以下浙大官方主机：

- `zjuam.zju.edu.cn`、`identity.zju.edu.cn`
- `zdbk.zju.edu.cn`、`courses.zju.edu.cn`
- `ugrs.zju.edu.cn`、`sztz.zju.edu.cn`
- `www.zju.edu.cn` 及连接器为学院公开资料声明的浙大官方子域名

个人账号读取属于本机兼容连接，不代表浙江大学官方开放 API；账号登录、验证码、站点登录态失效或网络不可用时，插件会返回明确的 `partial`/`failed` 状态，不会把失败说成“没有记录”。

## 打包

在本目录执行：

```text
npm test
npm run package
```

生成的 `dist/campus-zju-public-plugin.zip` 可以在“在场”的接口设置中导入。插件版本为 `1.2.0`，首次安装后默认停用，需要在宿主界面审核并启用。安装后可使用 `school.read` 的 `learning_courses` 查询学在浙大课程；传入 `courseId` 可读取该课程的活动。课程和活动缓存超过 48 小时后会刷新，网络失败则保留上次快照并标记为 `partial`。

## 当前边界

单元测试使用固定响应验证协议、解析、连接器状态和失败边界，不代表远程校园网站当前可用，也不代表本机已经配置浙大账号。真实运行仍取决于官方站点的网络、页面结构、Python 运行时和登录状态；图片型校历不会被插件自行 OCR。
